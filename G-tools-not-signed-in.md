## Summary

Settings → Tools says the same thing three times when no image provider is signed in: "Image provider: **No image provider available**", then "**Shisa.AI: Not signed in.** Add a key or sign in under Model providers." and "**OpenRouter: Not signed in.** Add a key or sign in under Model providers."

## Steps to reproduce

1. Use an installation where neither Shisa.AI nor OpenRouter is signed in (for example only a custom provider).
2. Open Settings → Tools.

Expected: one line that no image provider is set up, with one link to Model providers.

Actual: three lines as above.
