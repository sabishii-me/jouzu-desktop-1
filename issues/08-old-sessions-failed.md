TITLE: Some saved sessions open normally but are then marked Failed, or say "The runtime could not open this session"
LABELS: bug,severity: medium
## What happens
Two kinds of saved sessions behave inconsistently: one whose last line was cut off (for example by a power loss) and one that contains an entry type this version does not know.
- Sometimes the session opens and its messages show with a normal composer; afterwards the sidebar marks it with a red Failed icon.
- Sometimes opening it shows "The runtime could not open this session." with Restart session.

The host log records the runtime's answer "History contains an invalid entry identity." for these sessions.

## Steps
1. Have a saved session whose file ends in a cut-off line, and one with an unknown entry type.
2. Open each from the sidebar, then open another session.

## Environment
develop 3ada3c9, jouzu 0.2.5, desktop browser, English and Japanese.
