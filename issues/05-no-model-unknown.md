TITLE: With no model available, a new session shows the model as "unknown" and gives no way forward
LABELS: bug,severity: medium
## What happens
When no provider is configured, a new session shows:
- the model picker labelled `unknown` (also in the Japanese interface);
- a Send button that looks available;
- no notice that a model is needed and no way to connect one from there.

## Steps
1. Start with a data folder that has no provider (or remove the only one).
2. Start a new session and look at the composer.

## Environment
develop 3ada3c9, desktop browser (1280 and 1440 wide), English and Japanese, fixture data.
