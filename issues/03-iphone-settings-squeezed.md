TITLE: iPhone Safari: Settings opens as the desktop two-column dialog; tab names and fields are cut off
LABELS: bug,severity: medium
## What happens
On iPhone, Settings opens as the desktop two-column dialog shrunk to the screen: the dialog is 370 px wide and its content column only 199 px (English) / 184 px (Japanese).
- Tab names run into the column divider ("Model providers", "モデルプロバイダー").
- Fields and buttons are cut short or wrap (for example "No image prov…").
- An error notice inside Settings is squeezed into the same narrow column.

On iPad the tab names and content fit.

## Steps
1. Open the web client in Safari on an iPhone.
2. Open Settings; look at Model providers, Tools, System and Language, in English and Japanese.

## Environment
develop 3ada3c9, Safari on iOS 26.5 (iOS Simulator, iPhone 17 portrait), real taps.
