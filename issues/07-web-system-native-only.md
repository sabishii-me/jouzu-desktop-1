TITLE: Web client: Settings > System shows both versions as "Unavailable" and offers desktop-only actions
LABELS: bug,severity: low
## What happens
In the web client (a browser connected to the host), Settings > System shows "Current version Unavailable" for both Jouzu and Jouzu Desktop, and offers "Repair Jouzu" and "Open the log folder". The versions are only read through the desktop app, so a browser never has them, and the two buttons are desktop actions.

## Steps
1. Open the web client in a browser.
2. Open Settings > System.
