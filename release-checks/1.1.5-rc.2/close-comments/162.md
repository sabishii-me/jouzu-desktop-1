Fixed in **1.1.5-rc.2** (QA channel) by #223 (commit 21ba526; release commit 120b2f0).

**What changed:** Messages waiting when the host restarts come back after the restart, paused, instead of being lost.

**Verified on 1.1.5-rc.2** with the independent QA playbook (deterministic local provider, throwaway data dirs), compared with 1.1.4 on the same setup.
Where: Windows 11 x64 release packages (English and Japanese) and a Linux build of the release commit (English and Japanese).
- Restart the host with a message waiting: it comes back and continues after the restart. Linux en/ja pass; Windows ja 3 of 3.
- One Windows en run failed; the same case also failed on 1.1.4 there and passed on rerun (flaky, not a regression).

**Regression scenario:** QA playbook case "#162 Waiting messages come back paused after a restart".
